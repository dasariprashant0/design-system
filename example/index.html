Principles

Seven rules decide almost every choice. When a screen feels wrong, one of them is usually broken.

  • Tokens onlyNo raw hex, font size or spacing number in a screen. If a value is missing, add a token first.
  • Rules, not boxesSeparate things with 1px lines and space. Use a card only when the box itself means something.
  • One accent, used sparinglyIt marks the current thing, the one action, or a warning about loss. Over about 5% of a screen, cut some.
  • Ink density before colourTell kinds apart with five ink steps and a hatch, never new hues.
  • Plain wordsSay what happened and what to do next, in short sentences. No jargon, no "Oops".
  • Square and quietRadius is 0. No shadows except the toast. No gradients except the hatch.
  • Undo over confirmDestructive actions run and offer Undo in a toast. A dialog only when undo is impossible.

    Do and don't

    Do

    • Use tokens and kit classes
    • Buttons are verbs: Save, Open folder
    • Errors say what happened, then what to do
    • Mark status with a word or shape as well as colour
    • Check in all three themes at 900px wide

    Don't

    • Raw colours, font sizes or spacing in a screen
    • Border radius, shadows, gradients or blur
    • Icon fonts, UI libraries, Tailwind
    • A second accent colour in one app
    • Centred body text, exclamation marks, emoji
