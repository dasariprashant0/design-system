# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. Include the component, the steps to reproduce and the version.

You can expect a reply within a week. Fixes ship as a patch release and are noted in [CHANGELOG.md](CHANGELOG.md).

## Scope

The packages `@monoline/css`, `@monoline/react` and the `monoline` CLI. The CLI downloads component source from a registry you choose; only use registries you trust, and read what it writes.

## Supported versions

The latest minor release.
